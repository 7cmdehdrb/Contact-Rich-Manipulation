# SweepPolicyCube 작업 지침

이 디렉터리 또는 하위 파일과 관련된 분석, 구현, 리뷰, 문서 변경을 시작하기 전에
반드시 [`PRINCIPLES.md`](./PRINCIPLES.md)를 처음부터 끝까지 읽고 준수한다.

- 사용자의 현재 요청과 원칙이 충돌하면 원칙을 묵시적으로 변경하지 않는다. 충돌
  내용을 사용자에게 알리고 명시적인 결정을 받는다.
- 사용자가 원칙 추가 또는 변경을 명시적으로 요청한 경우에만 `PRINCIPLES.md`를
  갱신한다.
- 구현을 변경할 때는 관련 원칙이 코드, 테스트, README에 계속 반영되어 있는지
  확인한다.
