# Tool과 Wrist 점유를 반영한 Scene 생성 로직

Tool은 Wrist를 통해 연결되어 있으며, 밀기 중에도 **월드 좌표의 -y 방향으로 공간을 점유한다.** 따라서 타겟 이동 경로의 캡슐을 비우는 조건에 더해, 그 캡슐의 각 x 위치에서 전면까지 이어지는 공간을 비운다. 넓은 조작 영역도 같은 방향으로 확장하고 RED를 제외해 GRAY를 만든다.

이 로직은 시뮬레이터 없이 실린더 중심 좌표와 직선 밀기 명령을 생성한다. 방향·거리의 균형을 먼저 정하고, 장애물 배치 실패 시 해당 명령을 유지한다. 모든 계산은 cm 단위의 2D 기하 계산이다. 모델 식별자는 `wrist_downward_v2`다.

## 좌표계와 배치 영역

작업판은 `W = [-50, 50] × [0, 40]`이다. 전면 `y=0`은 로봇이 진입하는 열린 경계이며, 측면 `x=±50`과 후면 `y=40`은 벽이다. 실린더는 반지름 `r=4`, 높이 `10`이다.

물체는 전면에서도 작업판을 벗어나지 않아야 한다. 반지름과 경계 여유 `m_w=0.5`를 반영한 물체 중심 영역은 다음과 같다.

\[
W_{obj}=[-45.5,45.5]\times[4.5,35.5]
\]

타겟 시작 영역은 `T=[-30,30]×[12,28]`이다. 손가락 접근을 위한 회전 경로가 측면·후면 벽을 넘지 않도록 제한한 영역이 `T_safe`이며, 기본 설정에서는 `T_safe=T`다. 목표 위치도 `W_obj` 안에 있어야 한다.

## 방향과 거리를 먼저 생성

방향각은 `[0,2π)`, 이동 거리는 `[5,20]`에서 생성한다. 0도는 +x, 90도는 +y, 180도는 -x, 270도는 -y다. 이 결합 공간을 기본 `24×8`개 구간으로 나누고, 각 주기에서 모든 구간을 한 번씩 무작위 순서로 방문한다. 각 구간 안에서는 연속 균일분포로 값을 뽑는다.

\[
d=(\cos\theta,\sin\theta),\qquad\Delta=Dd
\]

명령을 만족하는 타겟 영역을 먼저 계산한다.

\[
F=T_{safe}\cap(W_{obj}-\Delta)
\]

`F`의 축별 하한은 두 직사각형 하한의 최댓값, 상한은 상한의 최솟값이다. 이 교집합에서 타겟 `p_0`를 균일하게 생성하고 `p_g=p_0+Δ`로 목표를 정한다. 직사각형은 볼록하므로 두 끝점이 `W_obj` 안에 있으면 타겟 중심의 전체 직선 경로도 안에 있다.

타겟의 위치 분포는 명령에 조건부이므로 원래 시작 직사각형의 무조건부 균일분포와 달라진다. 방향·거리의 균등성을 우선한 선택이다. 모든 방향과 최대 거리에서 유효한 위치가 존재하지 않는 설정은 생성 전에 거절한다.

## RED를 전면까지 확장

타겟 중심의 경로를 다음 선분으로 둔다.

\[
S=\{p_0+sd\mid 0\le s\le D\}
\]

기존 RED 캡슐의 반경은 두 실린더 반지름과 여유를 더한 `R_R=2r+δ_R=8.3`이다. 새 RED는 이 캡슐의 모든 점을 **월드 -y 방향으로 전면까지 확장**한 영역이다.

\[
Z_R= W_{obj}\cap
\{(x,y)\mid\exists y'\ge y:\operatorname{dist}((x,y'),S)<R_R\}
\]

어떤 x에서 기존 RED의 가장 높은 위치가 `y_top(x)`라면, 그 x에서는 물체 중심 하한 `y=4.5`부터 `y_top(x)` 아래까지 모두 RED다. 캡슐의 곡선 상단과 대각선의 기울어진 상단 경계를 유지한다. x 방향 범위는 원래 캡슐의 사영 범위다.

\[
\min(p_{0x},p_{gx})-R_R<x<\max(p_{0x},p_{gx})+R_R
\]

확장 방향은 목표 방향 `-d`와 관계없이 항상 `(0,-1)`이다. 예를 들어 +x로 미는 수평 경로 아래에 장애물이 있으면, 타겟 자체의 경로에서 멀더라도 Wrist 점유 규칙에 위배되어 생성하지 않는다. +y 또는 -y 이동에서도 같은 월드 -y 규칙을 적용한다.

[기존 Zone과 새 Zone의 비교 그림](../outputs/scene_randomization/zone_logic.png)에서는 수평 경로 아래의 장애물이 기존 규칙에서는 허용되지만 새 RED에서는 금지되는 모습을 확인할 수 있다.


### 격자 없이 계산하는 판정식

선분과 아래쪽 반직선의 합집합 영역을 `S_down=S+{(0,-t) | t≥0}`로 정의한다. 후보 중심 `q=(q_x,q_y)`에서 이 영역까지의 거리는 다음과 같다.

\[
h(q)^2=\min_{0\le s\le D}
\left[(q_x-p_{0x}-sd_x)^2+
\max(q_y-p_{0y}-sd_y,0)^2\right]
\]

그러면 `h(q)<8.3`인지 확인하는 것만으로 새 RED를 정확히 판정한다. 영역 바깥의 최단점은 선분 또는 양 끝점의 아래쪽 반직선에 있고, 내부의 거리는 0이다. 생성 코드는 이 경계 거리와 후보 x에 해당하는 아래쪽 반직선 거리를 벡터화해 계산한다. 수평·수직 경로도 같은 방식으로 처리하며, 위치를 격자로 반올림하지 않는다.

`downward_sweep_distance2()`가 `h²`를 계산하고, `zone_masks()`가 RED·GRAY·뒤쪽 배치 마스크를 만든다. 그림에서만 색칠을 위해 격자를 사용한다.


## GRAY와 WHITE 정의

넓은 경로 주변 캡슐도 월드 -y로 확장한다. 기본 반경은 `R_G=14`다. 이 영역은 타겟 가까운 조작 공간뿐 아니라 Tool/Wrist 점유 공간의 양옆에 장애물을 만들기 위한 기준이다.

뒤쪽 접근 영역은 타겟의 밀기 방향 좌표계로 정의한다.

\[
\xi=(q-p_0)^Td,\qquad
\eta=(q-p_0)^T(-d_y,d_x)
\]

\[
B=\{q\mid -16\le\xi\le0,\ |\eta|\le11\}
\]

최종 Zone은 다음과 같다.

\[
Z_G=\left(W_{obj}\cap(\{q\mid h(q)<14\}\cup B)\right)\setminus Z_R
\]

\[
Z_W=W_{obj}\setminus(Z_R\cup Z_G)
\]

뒤쪽 장애물의 배치 영역은 `B∩W_obj∖Z_R`이다. 새 RED와 겹치는 뒤쪽 공간에는 장애물을 놓지 않는다. 기본 설정에서 뒤쪽 최소 1개는 여전히 반드시 생성한다. 나머지 GRAY 물체가 뒤쪽에 추가로 들어갈 수 있으므로 이 조건은 최소 개수다.

일반 GRAY 후보는 확장 캡슐과 뒤쪽 직사각형을 모두 포함하는 경계 직사각형에서 뽑는다. y 하한은 물체 중심 영역의 전면 `4.5`다. 기존 타겟 주변 캡슐에서만 후보를 뽑으면 Wrist 양옆의 새 GRAY를 충분히 샘플링하지 못하므로, 후보 생성 범위도 함께 확장한다.

Zone은 **장애물 중심 기준**이다. 장애물 반지름이 이미 RED 반경에 포함되어 있으므로, 그림의 장애물 원 외곽이 RED 색상에 일부 걸친다는 이유만으로 충돌이라고 판정하지 않는다. 모든 배치 후보는 별도로 `W_obj` 안에 있는지 검사한다.

## 장애물과 접근 경로 배치

먼저 작은 원으로 근사한 손가락의 접근 경로 하나를 확보한다. 기본 원 반지름은 `finger_thickness/2=1`이다. 전면 밖 `y=-2`에서 타겟 아래로 진입하고, 타겟 주변 반지름 `5.25`의 16각형에서 짧은 방향으로 돌아 밀기 방향 반대편으로 이동한다. 마지막 `0.25`를 진행해 접촉점 `p_0−5d`에 도달한다. 경로 선분 전체가 타겟·벽을 피하도록 구성한다.

장애물은 기본 총 6개이며 **뒤쪽 GRAY 1개 → 나머지 GRAY 2개 → WHITE 3개** 순서로 배치한다. 슬롯마다 32개의 후보를 각 Scene에 대해 동시에 검사한다.

| 검사 | 통과 조건 |
|---|---|
| Zone | 슬롯의 지정 Zone에 속하고 새 RED 밖에 있음 |
| 작업판 | 중심이 `W_obj` 안에 있음 |
| 초기 간격 | 타겟 및 기존 장애물과 중심 거리 `≥9.6`, 표면 간격 `≥1.6` |
| 셀 분포 | 작업판의 5열×2행 셀에 타겟 포함 최대 3개 |
| 국소 밀도 | 반경 18 안의 다른 물체 최대 3개; 기존 물체의 이웃 증가도 검사 |
| 손가락 접근 | 모든 경로 선분에서 장애물 중심 거리 `≥5.1` |

여러 후보가 통과하면 현재 물체 수가 적은 셀에 더 높은 확률을 부여해 하나를 고른다. 장애물이 없는 셀을 강제로 모두 채우지는 않는다. 후보를 배치하지 못하면 정해진 횟수만큼 다시 뽑고, 슬롯 실패 시 Scene 배치를 다시 만든다.

접근 경로 예약은 작은 손가락 원의 접근 가능성을 보장한다. 새 RED는 밀기 구간에 대해 요청한 Tool/Wrist의 -y 점유 규칙을 적용한다. 접근 중 실제 Wrist 전체의 경로와 실제 손 형상·로봇 운동학은 이 모델의 검사 범위에 포함하지 않는다. 실린더의 높이·전도·마찰·물체의 동역학도 계산하지 않는다.

## 전체 실행 순서와 실패 처리

```text
설정과 전체 방향·거리의 기하적 가능 범위 검사
방향×거리 구간 스케줄에서 연속값 샘플링

각 명령에 대해 배치 시도 상한까지 반복:
    명령을 만족하는 교집합에서 타겟 위치 생성
    목표 위치 계산
    손가락 접근 경로 구성
    -y로 확장한 RED / GRAY / WHITE 판정식 설정
    뒤쪽 GRAY → 나머지 GRAY → WHITE 순서로 장애물 배치
    슬롯마다 Zone·경계·간격·밀도·접근 선분 거리 검사
    전체 배치 성공 시 Scene 저장
    실패 시 같은 방향·거리로 타겟과 장애물 배치만 재시도

시도 상한 도달 시 실패 인덱스·명령·원인을 반환
반환된 전체 좌표로 독립적인 기하 검사 수행
분포 통계, Scene 그림, NPZ, 보고서 저장
```

성공률이 높은 방향만 남지 않도록, Scene 재시도에서 방향·거리를 바꾸지 않는다. 간격·밀도·뒤쪽 개수·RED 조건도 자동으로 완화하지 않는다. `GenerationError`를 무시하고 성공한 Scene만 모으면 편향이 다시 생길 수 있으므로 실패를 명시적으로 처리한다.

같은 생성기를 계속 사용하면 구간 방문 스케줄도 이어진다. 처음부터 누적한 n개에서 결합 구간별 개수 차이는 최대 1개다. 병렬 실행에서도 부모 프로세스가 전체 명령을 먼저 분배하므로 작업 프로세스 수에 따라 명령 분포가 달라지지 않는다.

계산은 Scene·후보 축에서 NumPy로 벡터화하고, 기본 512개씩 나누어 메모리 사용량을 제한한다. RED 확장을 위한 반복 격자 탐색이나 경로 점 샘플링이 없어 후보 판정은 상수 개수의 거리 연산으로 끝난다. 시각화와 압축 저장은 생성 시간 측정에서 제외한다.

## 검증과 결과 파일

검증기는 생성 시의 후보 수용 결과를 사용하지 않고 최종 좌표에서 조건을 재계산한다. -y 확장 영역은 양 끝점 좌표, 선분 거리, 후보 x에서의 상단 선분 높이를 이용한 내부 판정으로 계산한다. 생성 코드의 방향·거리 기반 계산과 서로 다른 방식으로 확인한다.

`wrist_projection_obstacle`은 새 RED에 장애물이 존재하는 Scene 수다. `wrist_projection_clearance_cm`는 확장한 중심 경로로부터의 최소 거리에서 두 실린더 반지름 8을 뺀 값이다. 기본 조건은 이 여유가 `≥0.3`인 것이다. `red_obstacle`과 `target_sweep_clearance_cm`는 기존 타겟 직선 경로에 대한 검사도 유지한다.

기본 설정과 seed `20261013`, NumPy 1.26.0으로 10,000개를 생성한 단일 프로세스 실행에서 모든 기하 검사를 통과했다. 3개 Scene이 한 번씩 재시도했고, 방향·거리 구간 192개에는 각각 52~53개가 생성되었다. 최소 확장 경로 여유는 약 `0.300176`, 초기 표면 간격은 약 `1.600754`였다. 생성 시간은 `2.360초`, 배치 평균은 `0.236 ms/Scene`이었다. 검증 시간은 별도 `0.078초`였다.

같은 조건에서 2개 프로세스로 실행한 결과도 10,000개 모두 기하 검사를 통과했다. 생성 시간은 `1.313초`, 배치 평균은 `0.131 ms/Scene`이었다. 병렬 측정에는 프로세스 시작과 결과 수집도 포함한다. 두 측정은 각각 따로 실행했으며, 하드웨어·난도·부하에 따라 시간은 달라진다.

자동 테스트 21개는 4,096개 Scene의 모든 기하 조건과 수평·수직·대각선 확장, 상단 경계 보존, 전면 GRAY 샘플링, 확장 영역의 독립 계산, 배치 재시도에서 명령 유지, 병렬 처리, 구형 NPZ 감지 등을 검사한다.
