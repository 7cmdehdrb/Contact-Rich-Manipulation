inspire_wrench_v0 를 상속한 inspire_wrench_v0_1 환경을 만들어줘.

이 환경은 다음과 같은 변경 사항을 가진다.

1. target_contact 보상의 삭제
2. target_goal_distance 보상의 변경

- Contact 유지 조건 하에서만 보상을 받도록 변경. Contact 유지 조건이란, target_contact와 같이 핸드와 물체 사이에 발생한 Net Force가 0.01일 때 참인 트리거가 있고, 이전 상태의 트리거와 현재 상태의 트리거가 모두 참인 상태를 의미한다. 
- 각도 조건을 추가. 지금 보상 구조에서 계수 알파를 추가한다. 이 알파는 다음과 같이 정의된다. 목표 지점 -> 시작 물체 위치 벡터와, 목표 지점 -> 현재 물체 위치 벡터 사이의 코사인 유사도. 따라서, 거리를 좁힘 + 정확한 각도로 밀어냄 + 접촉 유지. 이 3개 조건을 동시에 만족하는 보상 식으로 구성된다.

3. 목표 지점의 간소화

- Feasability 테스트를 위한 변경 사항이다.
- target_goal_direction_deadzone 커리큘럼 삭제, 항상 40도로 설정
- 목표 거리의 설정 범위를, 지금의 절반 수준으로 설정

이 변경을 통하여, 상대적으로 쉬운 케이스만 만들어내서 (1), (2) 변화를 통한 효과를 빠르게 파악하기 위함이다.
