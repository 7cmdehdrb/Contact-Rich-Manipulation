위 폴더에 작성된 문서들과 페이지를 참고하여 다음을 수행해라:

"src/inspire_sweep_baseline/inspire_sweep_baseline/__init__.py" 에 적혀있는 "모든 환경" 에 대한 독립적인 문서 생성

1. 이미 작성된 독립 환경 문서는 새로 작성할 필요 없음
2. 새로 작성되는 독립 환경 문서는, 이미 작성된 환경 문서보다 훨씬 적은 정보를 기입함 (이미 폐기한 환경이기 때문)
    - 기본 구성 설명
    - 관측 정보 설명
    - 보상 구조 설명 (전체 테이블 하나와, 특별히 설명이 필요한 보상 - 그 환경에서 특수하게 변경된 보상이라면 - 어느 정도의 설명 추가)
    - 터미네이션 설명 (테이블)
    - 커리큘럼 설명 (테이블)


---

각각 독립적인 문서 작성과 더불어, 환경 계층 구조를 설명하는 문서도 작성한다.

- 베이스 환경에서 어떻게 뻗어 나오는지, 일종의 디자인 차트 (Flow Chart 비슷한 느낌) 가 필요하다.
- 그리고 각 환경에서 건너갈 때, "어떤 의도를 가지고" 어떤 변경을 가했는지 설명하는 내용을 포함한다.
- 이후, 각 환경을 설명하는 문서와 하이퍼링크를 추가한다. (상대 경로로 작성)

---

결과적으로, 나는 변화 파일을 보고, 이런 수정 사항이 있었군 하고 쉽게 확인한 다음,
각각의 환경의 자세한 정보를 확인하기 위해 하이퍼링크를 타고 들어가, 자세한 내용을 파악할 수 있는 그런 문서 집합을 원한다.
