Inspire-Wrench-v0_2 환경 문제점을 제시한다. 이를 개선한 Insire-Wrench-Refactor-v0 환경을 만들어라. 단, 상속 관계는 끊고, 새로운 CFG 클래스로 구성한다.
여기서 변경 없음이라고 말하는 것은, 반드시 Inspire-Wrench 계열을 다 뒤져서, 거기 안에 있는 함수에 있으면 변화 없음이라고 말하는 것임.

1. 앞서 파악한 물체 스폰 문제

- RESET 등에서 문제가 발생하여, 이를 조정한다.
- 기존에는 타겟 1 + 장애물 최대 16개(이론상)에서, 매번 랜덤화를 수행했다. 이 규칙을 변경한다. 로직은 다음과 같다.
    - 최초 초기화 때, 각 환경마다 랜덤화가 적용되어 서로 다른 마찰 계수, 물체 사이즈, 물체 질량이 지정된다. 이 지정은 reset해도 바뀌지 않는다.
    - 단, "서로 다른" 이라 함은, 겹치지 않아야 함을 의미하는게 아니다. 그냥 균등 랜덤 적용하면 된다.
    - 물체 수량도 고정한다. 각 타입당 2개씩, 총 16개의 장애물과, 실린더로 고정한 타겟 물체를 사용한다. 장애물은 선반 위쪽에 미리 스폰해있고, 환경 reset 때 마다, 그 중에서 N개를 선정하여 작업 영역 쪽으로 텔레포트 시키는 원리이다.
    - 이 방법을 통해 적절한 스폰 z를 사전에 알아서, 환경 초기화 때 걸리는 리셋 부담을 최소화 한다.

2. (확인 요망) 타겟 지점 스폰 규칙이 올바른지 체크해라. 

- 의도하는 스폰 규칙은, 12시, 6시 쪽에 각각 부채꼴 형태의 타겟 지정 금지 구역이 존재하여, 양 옆 + 사선 방향으로 밀기 이벤트만 발생하는 구조이다.
- 뭔가 왼쪽으로 미는 행동이 잘 안나오는 것 같아, 확인을 요청한다. 균등 샘플링인지도 검토해라.
- 또한, 타겟 목표의 시각화도, 3cm으로 설정하여 직관성을 높힌다 (물리 X, 시각화)

3. MDP

    1. 관측
        - joint pos(6), joint vel(6), hand config(2), ee pose(7), initial target state(3), goal(2), last action(8), tactile(17+17, 변경 내용은 후술), 캔슬링된 F/T(6)를 Raw 관측으로 설정 (변경 없음)
        - critic에는 원래 current target state(3)을 추가로 부여했는데, initial target state 을 current로 바꾸는 구조로 설정. 이를 통해 Critic, Actor의 입력 차원은 같다.
        - 장애물 인코딩은 Actor는 관측 가능한 장애물 & 확률 변조 적용, Critic은 모든 장애물 & 변조 없음, 64 -> 32 -> 16 압축 후, Raw랑 병합. 원시 장애물 관측은 [mask, x, y, z] 로 구성. (변경 없음)

    2. 환경 
        - UR5e + F/T + Hand 구성
        - 핸드는 기존 왼손에서, 오른손 모델로 변경, F/T 캔슬래이션과 Tactile 처리에 유의. 기존 왼손에서 Tactile 일부 수정 있었음
        - 핸드의 "손등" 에도 Tactile을 추가하고자 한다. 다만, 별도의 Mesh가 있는 것은 아니기 때문에, 손바닥 쪽에 있는 Tactile과 매칭되는 뒷면 영역들을 정의해두고, 거기에 힘이 들어오면 감지되도록 설정한다. 다만, 멀티 컨텍이 가능해야 함에 유의해라. 같은 물체에 2개의 접촉이 발생할 수도 있다는 의미이다.
        - 물체 갯수는 White 영역 0~3, Gray 영역 0~3에서 균등 샘플링
        - 목표 방향 및 거리는, 선반 내 유효 영역이라면 전부 가능하도록 설정.

테스트 1. 리셋 테스트

- 환경을 초기화 시키면서, 배치 오류나 기존처럼 물체가 허공에서 떨어진다거나, 이상한 타이밍에 스폰되지 않는기 검토해라.
- 타겟 목표점이 항상 균등하게 샘플링 되는지 확인해라. 거리보다는 방위를 중점으로 허용 범위 내에서 균등하게 샘플링 되는지 검토해라. 이는 특정 방향에 편향될 경우, 그 방향 밀기만 학습할 가능성이 있기 때문이다.

테스트 2. 리워드 테스트

동일 IsaacLab 환경 상에서, RL 학습이 아니라 룰 기반 제어를 수행한다.
목표점은 바로 왼쪽으로만 밀면 되는 케이스, 바로 오른쪽으로만 밀면 되는 케이스를 만들고, 장애물은 0개 스폰한다.
이 상태에서 손을 최대한 피고 손바닥이 왼쪽을 향한 상태로 물체 바로 옆으로 이동, 팔을 일자로 천천히 이동시켜서, 목표점에 도달하도록 제어한다.
이 때, 리워드(페널티)들을 기록하여, 의도한 대로 동작하는지 체크한다.
해당 과정은 32 벡터화로 수행하며, headless를 쓰지 않는다. (내가 보기 위함)

이 과정에서, Tactile 센서와 F/T 정보도 같이 기록하여, 다음을 검토해라.
- 미는 과정에서 Tactile 관측이 유의미하게 들아오는지, 들어오면 어떻게 활성화 되는지
- 최초 접근 및 미는 과정에서 발생한 Force/Moment가 비접촉 상태보다 유의미하게 차이가 나는지
