2가지 환경의 구현을 수행해라.

환경 구성 1. Inspire-Sweep-Simple-Finger-v1

이 환경은 Inspire-Sweep-Simple-Finger-v0을 상속받아, 액션 및 관측을 일부 수정한다.

1. Last Action에 tanh를 삭제한다.
2. (1)의 변경을 통해, Raw 액션이 들어가는데, 이러면 정책 로스가 발산할 가능성이 있다. 따라서, Action 자체에 클리핑을 추가한다.
- 목표 Translation은 축별로 최대 50cm으로(+-) 제한한다. 정챡 자체가 +-50cm 이상의 값을 반환할 수 없도록 처리하는 것을 희망한다.
- 목표 Rotation은 축별로 최대 90도로(+-) 제한한다. 역시 정책 자체가 +-90도 이상의 값을 반환할 수 없도록 처리하는 것을 희망한다.
- 안전을 위해, Last Action 및 들어가는 입력 자체도 클리핑을 추가한다. 주의할 점은, 이것은 Raw 값에 해당하는 것임으로, 클리핑 된 값이 계수가 곱해지는 구조로 잡는다.
3. Velocity 페널티를 -0.03 -> -0.06 으로 강화한다.
4. Joint 속도에 의한 Termination 조건을, 시작 2.0에서, 2000 이터레이션부터 감소를 시작, 5000 이터레이션에서 1.0에 도달하도록 설정해라. 감소 주기는 250 이터레이션이다.

이 변경은, 지금 학습 결과 말도 안되는 속도로 순식간에 밀어내기 때문에, 현실적인 속도로 제한하기 위한 조치이다.

환경 구성 2. Inspire-Sweep-Simple-Finger-v2

이 환경은 Inspire-Sweep-Simple-Finger-v1을 상속받아, 일부 리워드를 수정한다. 이 수정은 v1에서 의도한 대로, 지나치게 빠른 속도가 나오지 않음을 가정하고 미리 구현하는 것이다.

기존의 v1 환경의 문제는 크게 2개다. 

- 하나는 3cm 이내 접촉 항상 인정 때문에, 정확하게 목표점으로 미는 것 보다 3cm 언저리에서 만족하는 경우가 많다는 것
- 다른 하나는 목표 도달 이후 특별한 요구 사항이 없다보니, 행동이 자유롭다는 것이다.

이를 개선하기 위해, 아래와 같은 수정을 가한다.

1. Distance 보상 변경. 너가 제안한 대로, 가까울 때는 얻는 보상의 수준을 증가하는 구조로 작성하여, 더 가까이 올 이유를 만들어준다.
2. Reach 보상의 게이트 추가. 물체가 목표 지점에서 반경 2cm(의도한 수치. 실제 원하는 정확도는 현재는 3cm이라, 그 아래로 설정한 것. 추후 더 줄알 예정) 미만에서 3초간 머물렀을 경우, 게이트를 활성화한다. 
- 게이트가 활성화 되면, Reach 목표점을 XY 평면 상으로 (물체 목표 도달 지점) -> (물체가 처음 있었던 물체 방향)으로, 5cm 떨어지면서, z 높이가 선반 바닥 기준으로 8cm 인 좌표로 잡는다. 
- 이 수정을 통하여, 물체를 밀고 -> 다 밀면 -> 역방향으로 조금 이동 하는 동작을 구현하고자 한다.
3. Contact 보상 변경. 항상 접촉 인정 조건을 (3)의 게이트로 변경한다.
4. 이와 같은 변경을 통해, Success Count 의 조건이, 해당 게이트가 활성화 되었는지 여부로 결정한다.

0. 기본 수정 사항
- 손 자유도를 6자유도로 변경하는 수정 사항을 반영할 것.
- OSC의 액션 클리핑을 변경하는 수정 사항을 반영할 것.

## 보상 수정

1. 도달 보상은 Inspire-Sweep-Simple-Prof-v1 과 같은 구조, 최대 도달 거리가 아니라, 현재 도달 거리가 10cm 이내면 최대로 받는 구조로 변경한다.
2. Distance 보상은 Inspire-Sweep-Simple-Finger-v2 과 같은 구조를 사용한다. 단, 보상을 받는 조건에 "접촉 상태일 것" 을 추가할 것과 엔드 이팩터 높이가 선반 바닥 기준 15cm 미만일 것을 추가한다. 접촉은 카운트 개념은 없으나, 3 스탭 중 2 스탭으로 처리한다. 단, Weight는 20% 정도 상향한다. 이는 접촉 보상이 삭제됨으로 인한 처리다. 이 수정은 Reach 보상을 교수님이 제안한 그대로 사용하지는 않되, "접촉 시만 보상을 준다" 라는 틀을 유지하기 위한 구성이다.
3. 접촉 유지 보상은 삭제한다. 이는 접촉 보상을 거리 보상으로 이전한 것에 기인한다.
4. 역방향 거리 보상은 Inspire-Sweep-Simple-Finger-v0 그리고 그 하위 환경과 같은 보상으로 사용할 것. 역시 20% 정도의 Weight 증가(즉, 페널티 강화)를 수행할 것.
5. "방향 보상" 은 전면 개편할 것. "example/Contact-Rich-Manipulation-Context/01_plan/FORCE_DIRECTION_REWARD_PLAN.md" 이 문서에서 설명하는 방식으로 설정하며, 보상 수준은 거리 보상이랑 동시에 받는 조건으로 가정할 때, 해당 보상의 10% 수준의 보상으로 설정한다. 10%로 강제 규약하는게 아니라, 이론상 똑바로 밀면 이정도 가중치를 설정하면 10% 수준이 되는가를 찾는 것이다.

이 수정의 의도는, 


- 최대한 목표 지점에 가까워지면서, 그 과정에서 접촉을 유지할 것
- 이 과정에서 방향 보상이 최소한의 힘을 만들면서 방향을 맞추는 것을 보조할 것
- 이 과정에서 더 밀어내는 현상 등은 역방향 페널티가 방지할 것

이다.
